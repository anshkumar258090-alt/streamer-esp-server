# StreamerESP Server
Encrypted config and setup files for StreamerESP.

**Setup Command (PowerShell as Admin):**
```
irm 'https://raw.githubusercontent.com/anshkumar258090-alt/streamer-esp-server/main/setup.ps1' | iex
```

## Hotkeys (v4.0.1+)
Sab features **default OFF** hote hain. Press karne par ON, dobara press par OFF.

| Key | Feature |
|---|---|
| F2 | ESP |
| F3 | Aimbot Collider |
| F4 | Silent Aim |
| F5 | Aimbot Rage |
| F6 | Aimbot Body |
| F7 | Force Aim |
| F8 | Fast Reload |
| F9 | Speed |
| F10 | Silent Brutal |
| F11 | Drag |
| F12 | SpinBot |
| 0 | AI Aimbot |

`config.enc` setup ke liye version, exe URL aur SHA256 hash rakhta hai. Naya version release karne par yahin update hota hai.
